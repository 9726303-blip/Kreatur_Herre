★ ГЛАВНОЕ, ЧТО НУЖНО ПОНЯТЬ ★
-----------------------------
У сайта ДВЕ независимые части:

  1) КОД (внешний вид) — файлы index.html, styles.css, script.js.
     Меняется только при обновлении самих файлов на GitHub. Обычно вам не нужно.

  2) КОНТЕНТ (галерея, прайс, тексты, соцсети, контакты) — хранится в одном
     файле content.json. Именно его вы наполняете через админку.

❗ ВСЕ правки в админке сначала живут ТОЛЬКО в вашем браузере. Чтобы их увидели
   все (телефон, другие люди) — контент нужно ВЫГРУЗИТЬ на сайт (раздел 1).
   Если этого не сделать: у вас всё есть, а на сайте пусто/по-старому.
   Это самая частая причина «на сайте всё не так».


1. КАК ВЫГРУЗИТЬ КОНТЕНТ НА САЙТ
-------------------------------
Способ А — простой, без настройки:
   Админка → блок «Резервная копия контента» → «Скачать копию».
   Скачается файл content.json. Зайдите на github.com → репозиторий Portfolio →
   Add file → Upload files → перетащите content.json (рядом с index.html) →
   Commit. Через 1–2 минуты сайт обновится у всех.

Способ Б — удобный, одной кнопкой (нужен токен GitHub, настраивается ОДИН раз):
   Разовая настройка токена:
     1) github.com → войдите в аккаунт 9726303-blip.
     2) Settings (профиль) → Developer settings → Personal access tokens →
        «Fine-grained tokens» → Generate new token.
     3) Repository access: Only select repositories → выберите Portfolio.
     4) Permissions → Repository permissions → Contents → «Read and write».
     5) Generate token → СКОПИРУЙТЕ его (показывается один раз).
     6) В админке, блок «Опубликовать на сайт»:
          Владелец: 9726303-blip   Репозиторий: Portfolio   Ветка: main
          Токен: вставьте скопированный токен
     7) «Опубликовать сейчас». Через 1–2 минуты сайт обновится у всех.
   Дальше каждый раз: правите в админке → «Опубликовать сейчас».
   Токен вводить заново не нужно — он сохранён в браузере.

ВАЖНО про токен: это как пароль. Он хранится только в вашем браузере и НЕ
попадает на сайт. Если потеряете/утечёт — удалите его на GitHub, создайте новый.

ПОЧЕМУ НА МОЁМ ЭКРАНЕ ВСЁ ЕСТЬ, А У ДРУГИХ НЕТ?
   На вашем устройстве (где сохранён токен) сайт специально показывает ваш
   рабочий черновик, чтобы не терять несохранённые правки. Посетители видят
   только то, что вы ВЫГРУЗИЛИ. Чтобы посмотреть глазами посетителя — откройте
   сайт в режиме инкогнито или на другом устройстве/телефоне.


2. ЗАКАЗЫ И СОТРУДНИЧЕСТВО (форм нет — копируемые шаблоны)
--------------------------------------------------------
Форм заявок на сайте больше нет. Вместо них:
  • Готовый ШАБЛОН — посетитель жмёт «Скопировать шаблон», заполняет и присылает
    вам в личные сообщения.
  • Под шаблоном — жирная строка «Напишите мне в личные сообщения» и кнопки
    Discord / VK / Telegram.

Настройка в админке:
  • Текст шаблонов: «Редактирование текста» → «Блок Заказать» / «Блок
    Сотрудничество» → поля «Шаблон…». Можно задать на каждом языке.
  • Ссылки Discord/VK/Telegram: блок «Контакты для личных сообщений».
    Пустое поле просто не показывается на сайте.


3. ПРАЙС И КАРТА СОТРУДНИЧЕСТВА (картинки в блоках)
--------------------------------------------------
  • «Заказать коммишку» → раздел «Прайс»: до 6 крупных картинок, по 2 в ряд,
    БЕЗ обрезки.
  • «Предложить сотрудничество» → раздел «Карта сотрудничества»: так же, до 6.
Загрузка: админка → «Примеры работ в блоке …» → «Добавить изображение» (сразу
сохраняется). Подписи «Прайс»/«Карта сотрудничества» меняются в «Редактирование
текста» (Блок Заказать / Блок Сотрудничество).


4. ГАЛЕРЕЯ, ПРОЕКТЫ, ФИЛЬТРЫ
---------------------------
  • Галерея: «Добавить работу» (отметьте фильтры → загрузите картинку). Все
    работы в одинаковых аккуратных окнах. Клик по работе — просмотр в полном
    размере.
  • Мои проекты: «Добавить пост» (картинка + дата + подпись). Подпись задаётся
    отдельно на каждом языке.
  • Фильтры: блок «Фильтры галереи». Каждый фильтр — карточка с названием СРАЗУ
    на всех языках (русский/English/…). «Добавить большой/малый фильтр» — новый
    (большие — первая строка, малые — вторая), «Удалить» — убрать.

Все загружаемые картинки автоматически сжимаются, чтобы сайт не тормозил.


5. СОЦСЕТИ В ПОДВАЛЕ САЙТА
-------------------------
Блок «Социальные сети»: до 10 кнопок в самом низу страницы. «Добавить соцсеть» —
новая ячейка (название + ссылка), «Удалить» — убрать. Это отдельные кнопки, не
путать с Discord/VK/Telegram в блоках заказа (раздел 2).
Вставлять ссылку в поле — как обычно: Ctrl+V или долгий тап → «Вставить».


6. ТЕКСТ НА РАЗНЫХ ЯЗЫКАХ
------------------------
Админка → «Редактирование текста» → вверху список «Язык, который сейчас
редактирую». Выберите язык и впишите перевод любого текста (навигация, кнопки,
шаблоны, абзацы). Пустое поле = показывается стандартный текст.
При первом заходе посетителю автоматически всплывает выбор языка.


7. ЗАЩИТА, РЕЗЕРВ, СБРОС
-----------------------
  • Водяной знак на работах — блок «Защита контента».
  • «Скачать копию» / «Загрузить копию» — резерв всего контента в файл и обратно.
    Делайте резерв перед большими изменениями.
  • «Сбросить всё» — вернуть стандартный контент (галерея, тексты, прайс,
    контакты, картинки, водяной знак). Пароль и токен НЕ трогаются.

Кнопки внизу админки:
  «Применить (предпросмотр)» — сохранить и сразу показать на странице, не
                               закрывая панель.
  «Сохранить и закрыть»      — сохранить и закрыть панель.
  «Сбросить всё»             — вернуть стандартный контент.
  (Всё это сохраняет в вашем браузере. Чтобы увидели все — выгрузите контент,
   раздел 1.)
